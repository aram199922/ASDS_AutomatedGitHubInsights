# ASDS_AutomatedGitHubInsights

Automated GitHub Insights & Predictive Analytics API.

Our project will concurrently ingests data from the GitHub API to track emerging software trends.

This project is essentially a "digital scout" that scans GitHub to find the next big software hit before it goes mainstream.

It turns messy data into a simple "Yes/No" answer: Is this new software actually useful, or is it just getting empty attention?
